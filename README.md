# ANN-Classification-Churn
# 🌸 Iris Classification App using Streamlit & Random Forest

Built an interactive machine learning web app to classify Iris flower species using user input features.

## 🔧 Tech Stack
- Python
- Scikit-learn
- Streamlit
- Pandas, NumPy

## ⚙️ Features
- Real-time prediction using Random Forest Classifier
- Interactive UI with feature sliders
- Cached dataset loading for performance optimization
- Simple and intuitive visualization

## 📊 Model
- Algorithm: Random Forest Classifier
- Dataset: Iris dataset
- Task: Multi-class classification
